Se aprendera sobre: SCAM para LANs cableadas
1. Comprender las capacidades de observación del canal que puede tener una máquina
2. Comprender protocolos de acceso múltiple (PAM)
3. Comprender cómo funciona la Ethernet conmutada
4. Comprender la Ethernet rápida, gigabit Ethernet

Nos vamos a basar en 2 supuestos:
1. *Modelo de estaciones:* Hay N estaciones independientes que genera tramas para transmisión. Una vez generada una trama, la estación se ocupa en transmitirla y no hace otra cosa hasta que la trama se ha transmitido con éxito.
2. *Suposición de canal único:* hay un solo canal disponible donde todas las estaciones pueden transmitir y recibir
